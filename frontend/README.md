# SIFGUARD Frontend

Next.js frontend application for the SIFGUARD AI Safety Intelligence Platform.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/ladanikirtan10-cyber/sifguard&root-directory=frontend)

## 🚀 Quick Start

### Getting Started

Run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Environment Variables

- `NEXT_PUBLIC_API_URL`: (Optional) URL of the FastAPI backend. Defaults to `http://127.0.0.1:8000` when running locally.

### Deploy on Vercel

The easiest way to deploy this Next.js app is through [Vercel](https://vercel.com/new/clone?repository-url=https://github.com/ladanikirtan10-cyber/sifguard&root-directory=frontend).
